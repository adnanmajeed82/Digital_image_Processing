# 10 Basic Mobile Apps for Digital Image Processing Students
1. Image Negative Converter App

Concept: Point Processing
Function: Convert selected image to its negative
Tech: Bitmap processing, pixel inversion (255 - pixel)

2. Grayscale Conversion App

Concept: Color to Grayscale transformation
Function: Convert RGB images to grayscale using weighted method
Tech: ImageView, Bitmap editing

3. Image Brightness & Contrast Adjustment App

Concept: Intensity transformations
Function: Slider-based brightness/contrast controls
Tech: SeekBar, pixel intensity mapping

4. Image Thresholding (Binary Image) App

Concept: Global thresholding (Otsu optional)
Function: Convert image to pure black & white
Tech: Pixel iteration, threshold logic

5. Histogram Display & Equalization App

Concept: Histogram statistics, image enhancement
Function: Show RGB histograms + perform histogram equalization
Tech: GraphView library, pixel intensity probability distribution

6. Image Smoothing & Sharpening Filters App

Concept: Convolution masks
Function: Apply filters like

Average filter

Gaussian blur

Sharpen filter (Laplacian)
Tech: 3×3 kernel convolution on Bitmap

7. Edge Detection App (Sobel, Prewitt, Canny)

Concept: Gradient operators
Function: Detect edges using multiple methods
Tech: Convolution + threshold operations

8. Image Rotation & Scaling App

Concept: Geometric Transformations
Function: Rotate (90°, 180°), flip, scale percentage
Tech: Matrix transformations in Android

9. Face Detection App (Basic ML Kit)

Concept: Feature Extraction
Function: Detect faces in camera or gallery images
Tech: Google ML Kit Vision (beginner-friendly)

10. Color Filtering App (RGB Channel Isolation)

Concept: Color plane separation
Function: Show Red-only, Green-only, Blue-only filtered images
Tech: Pixel manipulation, channel extraction
